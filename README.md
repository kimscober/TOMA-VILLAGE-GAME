# TOMA - Toma / Okwewula Omupiira
Ugandan Village Dodgeball - Straight Version

**The Real Game:**
- 3 players: Thrower Left (8m), Thrower Right (8m), Dodger in Middle
- 2 throwers throw kaveera ball to hit middle player
- Middle player: step left/right, JUMP, DUCK, CATCH
- 3 lives, survival timer, points for each dodge

**Platform:** Android Unity 3D Portrait

**Controls:**
- Left: Joystick (move 2m left/right)
- Right: JUMP | DUCK | CATCH buttons

**Features:**
- Level system: speed increases every 30 sec
- Catch = thrower stunned 3s +10 points +1 life
- AdMob: Banner 320x50, Interstitial on Game Over, Rewarded for +1 Life
